# OpenSourceGuard

OpenSourceGuard 是面向开源项目维护者的本地控制中心：统一查看 GitHub、Gitee、GitLab 项目和 Issue，生成 Agent 修复方案，并在用户确认后执行操作。

## 为什么需要本地控制器

这个创空间负责产品介绍和在线演示。真实项目文件、Git 凭据和平台写操作应该留在用户电脑上的本地控制器中。

1. 下载本项目的源码。
2. 在本地双击 `start.bat`。
3. 在本地工作台连接 GitHub、Gitee 或 GitLab。
4. 所有代码读取和写入都由本地服务完成。
